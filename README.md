# 活侠传剧情索引

一个用来查《活侠传》原文、事件和分支的网页。打开网站即可使用，也可以下载 HTML 文件，在浏览器里离线打开。

| 栏位 | 用来做什么 | 试试看 |
| --- | --- | --- |
| **文本检索** | 按关键词查原文，也可以按发言人筛选。填了关键词后，名单会缩小到说过相关台词的人。 | 搜「极乐教」，展开「发言人」选一个角色，再点「定位到这句」看前后文。 |
| **路线图** | 按游戏时间看事件顺序和路线分歧，点节点打开剧情。 | 搜「总攻击」并点「定位」，再点图上的节点。拖动空白处可以移动，按住 Ctrl 滚动滚轮可以缩放。 |
| **事件目录** | 按事件名或脚本编号找剧情，查看已知时间、分支和对白。 | 搜「小梅共舞」，打开事件，在「回想式对白」里往下读。 |
| **旗标查询** | 查一个剧情状态何时被设置或检查，也能查道具在哪里获得或移除。 | 搜 `M20002`，查看「已经知晓了杏花仙的存在」在哪些片段被设置或检查。 |
| **条件查询** | 查某个判定或选项的要求，以及它出现在哪个剧情片段。 | 搜 `Ch_7_4_2_Break_01_007`，查看判定内容和使用位置。 |
| **代号查名** | 把成就、道具、事件等内部编号查成中文名。 | 搜 `成就_30020`，可以查到「折梅手」。 |
| **引经据典** | 查看剧情里的典故和对应原句。 | 搜「小梅共舞」，打开《老子》第八章相关条目，再点「定位到原句」。 |

从搜索结果打开对白后，可以点「返回结果」继续翻看。想知道同一段剧情还有哪些走向，就展开「剧情分支图」，或查看「接下来」和「场景内分支」。

资料基于本地游戏版本 `1.0.6001.0`。标为「待核」的时间或事件归属仍需核对。
